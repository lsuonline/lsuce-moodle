# moodle-local_checksummer

A Moodle local plugin and CLI utility that checksums a given folder and all subfolders and compares those against known values. 
It provides an administrative UI to schedule the process via an adhoc task.

## Features

- **Generate Mode**: Creates a manifest CSV containing the filename, size, and SHA256 checksum of every file in a directory. Also intelligently extracts modification time if the filename contains a timestamp suffix (e.g. `_1261705402.zip`).
- **Compare Mode**: Compares a directory against a known source manifest and generates a report detailing matched, mismatched, missing, and extra files.
- **Admin UI**: Manage settings, schedule background adhoc tasks, upload source manifests, and download generated manifests and reports.
- **CLI Utility**: For backward compatibility and system administration, a CLI script is provided that performs the same functions.
- **Robust Processing**: Uses database-backed state tracking for operations and supports adhoc task continuation, preventing timeouts on extremely large directories.

## Installation

1. Copy the `local_checksummer` directory into your Moodle `local/` directory.
2. The folder name must be exactly `checksummer`.
3. Log in as an administrator and follow the standard plugin installation process to upgrade the database.

## Usage: Admin UI

Navigate to **Site administration > Plugins > Local plugins > Checksummer Settings**.

1. **Directory**: Enter the absolute path to the directory you want to process on the server.
2. **Mode**: Choose between *Generate* or *Compare*.
3. **Output filename**: The name of the file to generate (e.g., `my_manifest`). The `.csv` extension is added automatically.
4. **Source Manifest**: If in *Compare* mode, select a previously uploaded source manifest to compare against.

### Action Buttons

- **Schedule Task**: Click this to queue an adhoc task (`\local_checksummer\task\run_checksummer_task`). The task will run during the next cron execution using the currently saved settings.
- **Upload Source Manifest**: Click this to upload a `.csv` manifest file to Moodle's file storage. This file will become available in the "Source Manifest" dropdown for Compare mode.

### File Management

The settings page lists:
- **Generated Files**: Manifests and reports generated by the adhoc tasks. You can download or delete them.
- **Source Manifests**: Files uploaded for comparison. You can download or delete them.

## Usage: CLI

The CLI script is located at `local/checksummer/cli/checksummer.php`. It utilizes the exact same core logic as the adhoc task.

**Generate Mode:**
```bash
php cli/checksummer.php <directory> <manifest.csv>
```

**Compare Mode:**
```bash
php cli/checksummer.php <directory> <source_manifest.csv> <report.csv>
```

### CSV Format

The generated manifest and expected source manifest follow this structure:
```csv
filename,size,sha256
```

The generated report follows this structure:
```csv
filename,status,expected_size,actual_size,expected_sha256,actual_sha256,actual_path
```

## Architecture

- `classes/checksummer.php`: The core service class containing the hashing and comparison logic. It acts as the single source of truth for both the UI/Tasks and the CLI.
- `classes/task/run_checksummer_task.php`: The Moodle Adhoc task.
- `settings.php` & `classes/admin_setting_actions.php`: Admin interface and custom setting element for rendering action buttons and file downloads.
- `lib.php`: Handles serving files securely from Moodle's File API via the `local_checksummer_pluginfile` function.
